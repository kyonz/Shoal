# shoal_skill (Resource)

A skill: reusable instructions and files that agents load on demand.

Maps to `/v1/namespaces/{namespace}/skills/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_skill" "python_testing" {
  name = "python-testing"
  spec = {
    description  = "How we write and run Python tests"
    instructions = file("${path.module}/skills/python-testing/SKILL.md")
    files = {
      "conftest-template.py" = file("${path.module}/skills/python-testing/conftest.py")
    }
  }
}
```
