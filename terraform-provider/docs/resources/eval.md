# shoal_eval (Resource)

An evaluation suite: cases run against a workflow or agent and graded.

Maps to `/v1/namespaces/{namespace}/evals/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_eval" "bugfix" {
  name = "jira-bugfix-regressions"
  spec = yamldecode(file("${path.module}/evals/jira-bugfix.yaml")).spec
}
```
