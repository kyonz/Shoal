# shoal_sandbox_profile (Resource)

A sandbox profile: backend (local, docker, kubernetes, e2b, space, remote), image, resources, network policy and TTL.

Maps to `/v1/namespaces/{namespace}/sandbox-profiles/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_sandbox_profile" "k8s_small" {
  name = "k8s-small"
  spec = {
    backend   = "kubernetes"
    image     = "ghcr.io/acme/agent-runner:2026.10"
    cpu       = 2
    memory_mb = 4096
    ttl       = "4h"
  }
}
```
