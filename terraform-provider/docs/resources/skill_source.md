# shoal_skill_source (Resource)

A skill source (marketplace): a git repository in the Agent Skills layout, a skill registry, or any installed skill source plugin, from which namespaces import skills. Tenant-wide and managed by tenant admins (`skill-sources:manage`); credentials are secrets in the `shared` namespace, never clear text.

Maps to `/v1/skill-sources/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
# A public git repository in the Agent Skills layout, pinned to a tag.
resource "shoal_skill_source" "anthropic" {
  name = "anthropic-skills"
  spec = {
    source = "git"
    title  = "Anthropic skills"
    config = { url = "https://github.com/anthropics/skills", ref = "main", path = "skills" }
  }
}

# A private repository: the token is a secret in the `shared` namespace.
resource "shoal_secret" "skills_token" {
  namespace = "shared"
  name      = "internal-skills-token"
  value     = var.internal_skills_token
}

resource "shoal_skill_source" "internal" {
  name = "internal-skills"
  spec = {
    source     = "git"
    config     = { url = "https://github.com/acme/agent-skills", ref = "v2.3.0" }
    secrets    = { token = shoal_secret.skills_token.name }
    namespaces = ["platform", "payments"]
  }
}

# A marketplace speaking shoal.skill-source/v1 (or a source run with shoal.sdk.skill_server).
resource "shoal_skill_source" "registry" {
  name = "acme-registry"
  spec = {
    source = "registry"
    config = { url = "https://skills.acme.internal" }
  }
}
```

## `spec` fields

A skills marketplace the tenant imports skills from (a git repository, a registry, or any
``shoal.skill_sources`` plugin). Tenant-wide; its secrets are read from the ``shared`` namespace.

These are the top-level fields of the SkillSource spec, the same as `spec:` in YAML. Nested objects are described in the
server's JSON Schema at `GET /v1/schemas` (also used by the UI builder for validation).
