# shoal_agent (Resource)

An agent: model, instructions, skills, tools, subagents, credentials, sandbox and limits.

Maps to `/v1/namespaces/{namespace}/agents/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_agent" "bugfixer" {
  name = "bugfixer"
  spec = {
    model        = "claude-opus-5-5"
    instructions = "You fix bugs. Always add a regression test and keep the diff minimal."
    skills       = ["python-testing"]
    tools        = ["shell", "read_file", "write_file", "list_files", "github.*"]
    credentials  = ["github"]
    sandbox      = "k8s-small"
    limits       = { max_turns = 120, budget_usd = 15, timeout = "90m" }
  }
}
```
