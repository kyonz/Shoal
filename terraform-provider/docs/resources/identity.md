# shoal_identity (Resource)

A person across systems (email, GitHub login, Jira account, Shoal users), used to attribute runs and pull requests to the human who drove them. Tenant-wide.

Maps to `/v1/identities/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_identity" "ada" {
  name = "ada"
  spec = {
    display_name    = "Ada Lovelace"
    email           = "ada@acme.example"
    github          = "ada"
    jira_account_id = "5b10ac8d82e05b22cc7d4ef5"
    actors          = ["user:ada@acme.example"]
  }
}
```
