# shoal_blueprint (Resource)

A blueprint in the tenant's catalogue: a versioned bundle of templated resources that namespace owners adopt into their namespace. Tenant-wide.

Maps to `/v1/blueprints/{name}`. `spec` is written as a plain object (HCL, or `yamldecode(file(...))`) and uses the same fields as the `spec` of the YAML resource.

## Example Usage

```terraform
resource "shoal_blueprint" "jira_bugfix" {
  name = "jira-bugfix"
  spec = yamldecode(file("${path.module}/blueprints/jira-bugfix.yaml")).spec
}
```
